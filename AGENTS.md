# Project documentation

Frontend docs live in `docs/` — read the relevant file before changing code:

- `docs/README.md` — overview, stack, env vars, quick rules
- `docs/STRUCTURE.md` — folder layout, data layer, auth flow, styling tokens
- `docs/PAGES.md` — every route, its access rules and composition
- `docs/UI_COMPONENTS.md` — shared UI kit; check it before creating a component
- `docs/CONVENTIONS.md` — naming, typing, component anatomy, styling, data and form rules

Keep these docs in sync when you add a page, a shared component or a new convention.
